# 活动编辑高保真原型

直接打开 `index.html`，无需构建、安装依赖或联网。也可在本目录运行 `python3 -m http.server 8766`。所有响应均为原型模拟；草稿只保存在浏览器 localStorage，不读写 Flutter 数据库。

## 设计说明

360 × 800 为默认手机画布。活动、时间是第一层；目标与节奏采用分隔行，摘要可直接读到归属和节奏，不把整个表单包装成大卡片。补充内容直接可写。目标和节奏最多展开一个，收起不会丢失输入。节奏状态确定后，一次呈现全部适用内容；复杂态使用同样的字号、间距与控件，并允许自然滚动。

保存固定在底部，草稿提示低强调。时间弹层只有内容区滚动，应用操作独立固定；模拟键盘只在外层扣除一次高度。时分钟选择器只更新该端点时分，不推测日期。首屏不会自动聚焦或弹键盘。

配色、字体、边框、圆角见 style.css 的变量和共享规则。基础正文 15px，控件最小高度 48px；选中用勾选符号与 aria-pressed 同时表达。模拟键盘收起按钮是开发演示控件。

## 状态索引

画布外“状态演示”可进入：

| 状态 | 进入与操作 |
| --- | --- |
| 01 最简新建 | 默认入口；写活动，确认时间，保存 |
| 02 已关联目标 | 目标摘要直接显示名称；展开可改选、创建、解除 |
| 03 卡住 | 原因、细节、接续点一次显示；状态切换保留字段 |
| 04 恢复 | 方式、感受、接续点；重复点击选择可取消 |
| 05 时间弹层 | 起止日期时间、独立精度；时钟按钮进入时分选择 |
| 06 时间与模拟键盘 | 外部键盘面板切换 220 / 300 像素 |
| 07 空目标列表 | 创建目标；名称留在弹层；取消不改变原关联 |
| 08 冲突 | 阅读设计资料，10月5日 11:00–11:30；只保留一个时间调整入口 |
| 09 保存失败 | 输入保留；重试保存 |
| 无建议 | 起止为空；手填后应用 |
| 多个候选 | 点击时间摘要，明确选择候选或手填 |
| 源记录不存在 | 独立不可保存状态；保留草稿退出或清理 |
| 已保存待收尾 | 重试刷新，不再次创建事实 |
| 已有归档引用 | 可保留或解除；归档目标不提供新关联 |
| 恢复草稿 | 恢复浏览器草稿，不覆盖成新时间建议 |

“创建目标响应”可选创建失败、创建成功但读取失败；后者重试读取已有对象，不重复创建。取消后再打开创建，仍可继续重试读取。已创建对象仍存在于本次演示目标列表。

“下一次保存响应”可选保存失败、成功后刷新失败、成功后清理失败。保存失败模拟下一次重试成功；冲突演示使用固定已有记录，必须实际消除重叠才能成功。“模拟草稿清理失败”用于退出或源记录不存在分支。

## 推荐演示路径

1. 选择 01，填活动。
2. 修改时间，试着输入无效结束时间并应用；检查原文和字段错误，然后修正为 11:15 应用。
3. 展开目标 → 创建 → 填名称 → 创建并关联。
4. 展开节奏 → 卡住 → 原因、细节、接续点；切恢复再切卡住。
5. 保存 → 冲突 → 调整结束时间到 11:00 → 应用 → 保存成功。
6. 另用状态面板演示无建议、候选区间、取消、失败与收尾。

# HOME-INTERACTION-01 实施报告

日期：2026-10-09（Asia/Shanghai），2026-10-10修正纸带断点与头部样式。任务：HOME-INTERACTION-IMPL-01 / 02。结果：**功能实施完成；平台与人工验收PARTIAL**。依据为[HOME-INTERACTION-01](../planning/HOME_INTERACTION_DESIGN.md)与Q-042–Q-044；用户在设计定稿后明确要求“开始实现”，后续明确纠正“时间轴是断点在最下方的纸带”。

## 交付

- 用一套自定义滑盖替换`NavigationDrawer`和横滑切日。快捷区默认左侧，可持久化选右侧；开合方向、顶部菜单与返回今天同步镜像。整张首页含底部记录按钮一起位移，遮罩只覆盖首页表面。
- 实现24dp意图距离、1.6水平比例、400dp/s快滑、50%端点、系统边缘保护、`min(360,W−64)`宽度、32%遮罩及1 / 700 / 1临界阻尼弹簧。手势可中途接管，取消 / 多指 / 应用离开前台收束到稳定端点，开盖立即停止时间轴惯性。
- 快捷区提供当日概览、当日复盘、条件性返回今天、我的目标与设置。打开时锁定已提交日期，阻止后台加载修改菜单中的“当日”。首页退出焦点 / 读屏范围，可见关闭按钮、遮罩、Escape与系统返回都先关闭快捷区，菜单项防重复提交。
- 时间轴仍以视口下沿保存阅读时刻；顶部日期与自动回展改为日期横线到达时间轴窗口上沿时共同触发，横线只从底部露出时不提前切日。本次有效下拖40dp后开始连续收起、120dp到紧凑态；中途松手 / 反向与上沿回展都从当前进度用不超过200ms连续收束，不再直接写端点。头部高度、失败提示或尺寸改变时保持同一时刻相对下沿的位置；程序定位、刷新、布局补偿与回弹不伪造收放。
- 底部提醒区域严格限定在实际今天；历史 / 未来浏览日不显示动作建议，也不显示普通问候卡。今天内仍随顶部进度连续收起 / 恢复。
- 恢复首版展开 / 紧凑头部结构：展开态保留原菜单、标题、返回今天、大日期与星期布局；紧凑态恢复菜单并入日期导航行、按实测宽度决定返回今天同行 / 第二行的方式。仅保留快捷区侧的必要镜像和后一天上限禁用。
- 普通日期导航以今天为上限。日历成功手选未来日后，该日成为本次浏览临时上限；返回今天成功后才清除。所有失败路径保留旧日期、窗口、阅读位置、顶部状态与旧上限。
- `AppPreferences`和现有Drift key-value偏好存储新增`homeQuickPanelSide`；设置 > 界面设置可选左 / 右，返回首页重读偏好并保留日期、阅读锚点与顶部状态。

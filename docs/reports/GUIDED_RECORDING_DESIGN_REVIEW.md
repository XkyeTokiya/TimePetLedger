# 活动问答样板设计审查

2026-10-05。用户否决上一轮界面，要求停止实施并使用Product Design重设计。本报告只审查现有样板，不代表认可或实现交付。

## 本次采集范围

独立Flutter Web样板，390×844逻辑视口，标准文字尺寸；场景为常用目标“备考”、节奏“卡住”、事项“理数据库的表关系”、10月5日10:30–11:15。截图为本次审查新采集并逐张打开核验；旧主页截图只作配色参考，不作为本次审查证据。

1. **节奏幕：层级需要重做。** [截图](assets/guided-recording-design-review/pd-record-01-rhythm.png)。目标、三个答案分别使用大卡片；目标操作和每个答案的解释长驻，占据问题之前及之后的主要空间。继续可达，节奏可取消，但画面强调较平均。建议目标压缩为稳定的上下文行，答案以同组标准选择组件呈现。
2. **事项幕：输入主次明确，但上下文重复加框。** [截图](assets/guided-recording-design-review/pd-record-02-activity.png)。目标卡片和节奏Chip继续占用上方，主要文字区与问题被推低。Unknown是可见捷径。建议保留一个轻量目标行及一句上幕回答，突出问题和事实输入。
3. **时间幕：直接操作缺失。** [截图](assets/guided-recording-design-review/pd-record-03-time.png)。端点整段组合成一个按钮，时分不能独立点击；用户先经过“调整时间”才能修改具体字段。截图中目标也未保持可见，尽管可访问树仍有目标节点；实现需要验证实际可见位置。建议日期和时分各有直接触控入口，主显示即编辑入口，移除额外调整按钮。
4. **调整层：重复呈现端点和提交动作。** [截图](assets/guided-recording-design-review/pd-record-04-time-sheet.png)。日期 / 表盘本身已采用成熟组件，但前置弹层重复起止信息，增加开层与“应用时间”操作。用户明确要求删除这个中间入口；取消不改草稿、无效区间不应用等合同仍需在直接组件路径实现。

## 重设计约束

- 三幕固定节奏 → 事项 → 时间；目标为长期时间归属，每幕轻量持续可见，可更换 / 取消。
- 三种可见节奏推进 / 卡住 / 休息，未选择也可继续；Unknown、原因 / 接续点选填等合同不变。
- 时间数值直接打开MD3表盘，日期直接打开MD3日历。起止精度独立，跨日明确选日期；不加入新推断。
- 沿用现有深蓝青色基线，以布局、间距、字级和同组关系区分方案；不通过重调品牌色掩盖层级问题。
- 先生成三份独立视觉方向供选择。当前不继续应用页面实现。

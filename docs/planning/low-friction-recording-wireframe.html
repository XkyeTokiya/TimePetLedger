    保存直接回账本，不弹补充问卷。想补充时可以在保存前展开，也可以从已存记录的详情进入。

    场景预填规则成功路径
    A · 明确空白点击 14:00—16:00，带入该区间，可缩短。输入“刷视频” → 保存 → 原位置看到记录。
    B · 普通入口有建议今天已有事实，尾部空白延伸至当前时刻，建议 14:00—16:00。记录一笔 → 看一眼时间 → 填活动 → 保存。
    C · 无建议当天没有事实，普通入口不猜整日；起止留空。填写活动 → 手动填时间 → 保存。修改时间不清活动。
    D · 想不起来沿用明确空白入口，无需填写活动名。选择“想不起来” → 保存 → 空白变成已交代的未知。

    共用一个活动编辑器；情境改变预填与文案，不改变事实合同。时间在独立弹层中临时编辑，应用有效值才写入草稿；取消或 Escape 不应用。起止精度独立，手动输入不自动变准确；数值不加“约”。区间必须为正且不与样例已有事实重叠。更正保留源记录，失败保留输入。

    新增和更正草稿按场景、记录身份隔离；返回保留本页会话草稿。切场景也可回来继续。重置只清当前场景。正式应用的跨重启草稿、真实数据库故障和平台键盘未在此 HTML 实现。原型保存是内存模拟。

    不新增分类、自动节奏推断、效率评分、自动时间拆分或覆盖。目标仅使用“毕业设计”“阅读与写作”两个示例；目标创建不是本轮评估重点。历史日候选 Gap、多日导航、睡眠与复盘不在本稿范围。

    验证重点：不展开补充能完成记录；Unknown 可保存且切换不清原文；时间取消保留旧值、无效应用停留；失败重试不丢输入；保存后不再追问；详情补充能修改原记录；缩短区间后剩余空白仍存在；320 px 与放大文字下主要动作可达。

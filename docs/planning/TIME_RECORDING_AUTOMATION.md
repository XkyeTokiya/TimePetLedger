## 简洁设计

进入新建 / 补记直接初始化完整日期时间。闭区间取前笔结束与后笔开始；起点已知的尾部取结束`max(当前时刻, 开始+30分钟)`；全开区间交给用户调整。普通新建使用2/3；明确Gap补记使用1/2；睡眠补记优先1/2。查询跨日真实记录，支持昼夜颠倒，不用午夜或08:00提醒时点推断睡眠。

两端已有正式记录的区间始终取真实边界，即使后一笔的已记录时间超过当前时刻。普通新建若30分钟初值会跨入已知记录，则交给用户手动选择，避免生成明知重叠的默认区间。

单端点点击后直接选时分，完成后接日期选择，组件取消保持原值，两组件完成直接更新缓存。日期自动建议考虑另一端；用户可以显式选择其他日期。删除两端时间弹层及其确认。时长点击后可选择保持开始推算结束，或保持结束反推开始。页面继续只有整笔提交主动作。

1/2每次进入重算，3留给用户在本次编辑中填写；新建 / 补记均不恢复旧缓存端点，其他草稿内容保留，同次编辑不随时钟变化。既有正式记录沿自身原区间编辑；已经提交但收尾失败的输入只恢复提交结果，不重新提交。新记录approximate，正式写入正区间、不重叠与失败反馈保持原合同。

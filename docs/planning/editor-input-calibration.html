按任务计算操作负担

以下从进入编辑页开始计算，假设时间建议正确、草稿存储成功；不把输入字数算点击，也不虚报现有版本节省百分比。原生日期/时间选择所需点击取决于控件，单列而不假称“一次完成”。

任务推荐路径键盘与操作
普通活动点活动框 → 输入 → 点保存2次点按＋输入；文字键盘唤起1次，无必须收起步骤
确认Unknown点想不起来 → 点保存2次点按，0次文字键盘；若已写过标题，转换保留原值
活动加目标/节奏写名称 → 点选目标/节奏 → 保存选择层可能临时收键盘；关闭恢复字段位置，不强迫再次输入或自动弹出。以实际平台测得的切换次数验收
更正睡眠时间打开时间层 → 选择端点/精度 → 应用 → 保存3次固定动作＋选择器内动作；主路径0次文字键盘。新建另需选择类型和填写两端点，不与更正混算
最简复盘点第一步 → 输入 → 保存2次点按＋输入，文字键盘唤起1次
完整复盘第一步 → 再写几句 → 概述 → 下一项 → 反思 → 保存4次点按＋三段输入；设计目标是一次持续文字输入会话，需真机验证焦点与IME没有闪退重开

焦点、返回与失败规则

  • 使用用户明确点击决定聚焦。打开时间/目标面板前记住原字段、选区和滚动；取消恢复原值。关闭后保留位置，只有明确“继续写作”才要求重新聚焦，不因关闭弹窗强行唤起键盘。
  • 复盘“上一项/下一项”只访问已展开的可写字段；最后一项工具条应显示“完成”。添加字段时不重建现有输入控制器；内容与光标不跳到开头。
  • 键盘打开时系统返回优先由平台收起键盘；再次返回才请求离开。应用顶栏返回明确执行原草稿离开流程，不绕过flush、草稿失败停留或放弃失败处理。
  • 保存条不能以“保存”掩盖草稿写入状态：存储失败显示可识别错误及重试；提交成功收尾失败进入只读结果态，替换主动作成既有“继续清理并刷新”，不保留重复提交按钮。
  • 保存校验失败定位首个错误字段；隐藏区域展开并滚动到位。时间冲突显示冲突事实与区间，进入时间修改，不自动覆盖或纠正。
  • 主样例仍是10月2日：Gap10:30–11:00预填approximate；睡眠为既有完整事实更正；复盘文案仅作样例。标题和备注可多行；Unicode长度合同不变。

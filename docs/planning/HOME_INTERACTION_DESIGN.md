# 首页交互完整设计：滑盖快捷区、日期浏览与顶部收放

日期：2026-10-09（Asia/Shanghai）。设计编号：**HOME-INTERACTION-01**。阶段：**设计评审稿；本轮只交付文档，未开始实现**。

本稿汇总本轮首页交互讨论。**已确认**表示用户明确决定或沿用的现行合同；**建议**表示本稿给出的具体设计，包含需要原型 / 真机校准的数值；**待确认**表示已询问、尚未收到答案的产品边界。不得把建议值或待确认选项登记为用户已选择。

产品依据为[源提案最新决定](../../time-ledger-domain-model-v4-proposal.md)、[Q-042](../domain/OPEN_QUESTIONS.md#q-042)及其职责对应文档。提醒卡与未来导航待确认分别登记[Q-043](../domain/OPEN_QUESTIONS.md#q-043)、[Q-044](../domain/OPEN_QUESTIONS.md#q-044)。真实比例、短段访问与定位继续引用[HOME-DESIGN-01](HOME_PROPORTIONAL_TIMELINE_DESIGN.md)，视觉、字体与主题引用[design.md](../../design.md)。本稿替换旧方案中横滑切日、阅读起点回展和侧边栏开合方式；既有实施报告仍是当时版本的证据。

## 2. 首页布局与左右两版

### 2.1 移动范围

首页作为一个完整表面平移，包含顶部菜单 / 日期 / 统计、时间轴、提醒卡区域及底部两个记录按钮。系统状态栏、系统导航区域与系统返回手势不作为首页内容平移。

建议使用以下层次：背景 → 快捷区 → 首页表面 → 首页表面内的遮罩。遮罩随首页移动，并只拦截首页表面上的点击；快捷区文字和按钮正常显示、可操作。打开后底部记录按钮仍随首页露出一部分，但被遮罩覆盖时不可触发记录。

建议不增加首页缩放、旋转或弹跳。位移与遮罩足以表达“把盖子推开”。

### 2.2 方向与按钮位置

以下方向始终指**手指 / 首页移动方向**。

| 快捷区设置 | 从关闭状态打开 | 从打开状态关闭 | 顶部菜单 | 返回今天 |
| --- | --- | --- | --- | --- |
| 左侧（默认） | 向右拖动：首页右移，露出左侧 | 向左拖动 | 左上 | 右侧 |
| 右侧 | 向左拖动：首页左移，露出右侧 | 向右拖动 | 右上 | 左侧 |

这套镜像关系同时适用于展开顶部和紧凑顶部。前一天 / 后一天仍按时间顺序排列：前一天在日期左侧，后一天在右侧；选择快捷区右侧不会反转日期的时间顺序。

只有浏览日期不是今天时，首页显示返回今天。主动选到未来也属于非今天。当天不保留该按钮的专属空位。

320dp、360dp及大字时允许顶栏换成两行，保持菜单与返回今天各自靠对应侧；日期导航独立成行。标准按钮触控目标至少48×48dp，不能通过压小文字或点击区域强塞单行。该要求沿现行[访问合同](../domain/OPEN_QUESTIONS.md#q-039)。

## 3. 一套快捷区

入口能力已确认；以下分组、顺序与文案统一是**建议布局**：

| 分组 | 内容 | 行为 |
| --- | --- | --- |
| 当前日期 | 显示当前浏览日期及今天 / 昨天等关系 | 只提供上下文，不新增第二个日期选择器 |
| 当日操作 | 当日概览 | 打开既有摘要页面，带入当前浏览日期 |
| 当日操作 | 当日复盘 | 打开既有复盘页面，带入当前浏览日期 |
| 当日操作 | 返回今天 | 仅非今天显示，成功后定位今天并展开顶部 |
| 全局入口 | 我的目标 | 打开既有目标页面 |
| 全局入口 | 设置 | 打开既有设置页面 |

用户确定入口名称为“当日概览 / 当日复盘”。“当日概览”承接现有摘要内容与统计，不在本轮重新设计图表。本文用“返回今天”指代现有“回到今天”动作；两处入口统一使用“返回今天”是本稿文案建议。

进入快捷区前停止正在进行的纵向惯性阅读，锁定此时的浏览日期与时间锚点。打开期间后台窗口加载或布局变化不能悄悄替换快捷区显示的“当日”。选择概览 / 复盘时只提交一次导航；进入后各页独立管理日期，返回首页保留原浏览日期、阅读位置和顶部状态。

建议菜单行以56dp为普通字阶基准，大字时按内容增高；所有行保持至少48dp点击高度，文字可换行。56dp是[Material 导航抽屉的尺寸参考](https://m3.material.io/components/navigation-drawer/specs)，并非本项目必须固定的行高。

## 4. 滑盖状态与关闭方式

设打开进度为 `p∈[0,1]`。两个稳定状态是关闭 `p=0`、打开 `p=1`；拖动和收束只是过渡。

| 状态 / 事件 | 处理 |
| --- | --- |
| 关闭 → 点菜单 | 向打开端点收束 |
| 关闭 → 符合方向的横向拖动 | 进入拖动，首页位移直接跟随手指 |
| 拖动 → 松手 | 按距离 / 速度选择打开或关闭端点，见 §5 |
| 收束 → 用户重新拖动 | 从当前实际位置接管，不跳回端点，不排队播放旧动画 |
| 打开 → 点首页遮罩 | 关闭，恢复首页交互 |
| 打开 → 反向拖动 | 跟手关闭，松手仍按同一套端点判定 |
| 打开 → 选择菜单项 | 消费一次操作，关闭快捷区并交接对应导航 / 日期定位 |
| 打开 → 系统返回或 Escape | 先关闭快捷区；再次返回才执行原页面返回逻辑 |
| 普通打开 / 关闭完成 | 保留浏览日期、阅读时间锚点和顶部展开 / 紧凑状态 |

系统返回、Escape、键盘焦点管理是本稿**建议的完整操作约定**。打开时键盘 / 读屏焦点进入快捷区，首页内容不参加焦点遍历；关闭后回到菜单入口或开盖前焦点。推荐快捷区提供可见“关闭”按钮，读屏名称明确为“关闭快捷区”，无需依赖滑动。

拖动中发生手势取消、多指干扰或应用失去前台时，取消本次导航意图，按当前进度收束到最近稳定端点；不触发记录或误进菜单项。点击项后禁用重复提交，避免连点产生两次页面跳转。

## 5. 横向手势识别与触发距离

本节数值均为**建议首版参数**。成熟框架的阈值用于建立量级，本项目根据中部起手、垂直时间轴和滑盖视觉作调整。

| 参数 | 建议值 | 用途 |
| --- | --- | --- |
| 起手识别距离 | `S=max(24dp, 设备提供的 touch slop)` | 过滤轻点和细微抖动；不是必须拖满后才渲染完整动画 |
| 水平意图比例 | `abs(dx) ≥ 1.6×abs(dy)`，且 `abs(dx) ≥ S` | 明确偏横向时接管，优先保护时间轴纵向阅读 |
| 方向锁定 | 同一次手势只认一种主轴 | 纵向滚动已接管后不因斜滑突然开盖；横向已接管后不切日或收放顶部 |
| 慢拖松手 | `p≥0.5` 打开，`p<0.5` 关闭 | 同一判定用于打开与关闭过程，含恰好50% |
| 快滑松手 | 朝某端点的速度达到400dp/s，优先收束到该端点 | 速度按本次横向拖动测量，不能用一帧抖动代替 fling |
| 系统边缘保护 | 每侧保留 `max(32dp, 该侧 systemGestureInsets)` | 此区域不抢占系统返回 / 导航；按钮仍可正常点击 |

Flutter 的默认 `kTouchSlop` 为18逻辑像素；这不是所有设备统一提供的值。其抽屉实现采用365逻辑像素 / 秒的 fling 判断及50%的非快滑端点判断。因此24dp与400dp/s是本稿取整、偏保守的项目建议，不是官方强制值。[Flutter touch slop](https://api.flutter.dev/flutter/gestures/kTouchSlop-constant.html)、[Flutter 抽屉源码](https://github.com/flutter/flutter/blob/master/packages/flutter/lib/src/material/drawer.dart)

系统可能先消费边缘滑动。保护区至少覆盖运行平台给出的手势 inset，32dp只是本项目额外的候选下限。[Flutter systemGestureInsets](https://api.flutter.dev/flutter/widgets/MediaQueryData/systemGestureInsets.html)

操作约定：

- 起手判断使用真实双轴位移；不把纵向位移置零后再计算方向。
- 接管后从手指当前位移连续映射首页位置；建议把识别所需的初始距离作为死区扣除，避免超过阈值时突然跳24dp。
- 时间轴点击与拖动由同一手势竞争决定；横拖获胜后，起手处的事实 / Gap / 记录按钮不再收到点击。
- 关闭状态下，朝未分配动作的方向滑动不切日期、不打开其他页面。
- 触控板滚动和鼠标滚轮继续负责正常阅读，不把水平滚轮意外解释为开盖；桌面 / Web通过菜单、关闭按钮、遮罩和键盘完成同等操作。

## 6. 快捷区宽度与遮罩

建议打开宽度：`D=min(360dp, W−64dp)`，其中 `W` 是首页实际布局视口的逻辑宽度。宽度按dp计算，不用屏幕物理像素或整台显示器宽度。以下为支持范围内的示例：

| 首页宽度 W | 快捷区打开宽度 D | 首页保留可见宽度 |
| --- | --- | --- |
| 320dp | 256dp | 64dp |
| 360dp | 296dp | 64dp |
| 412dp | 348dp | 64dp |
| 600dp | 360dp | 240dp |

360dp来自[Material 导航抽屉的尺寸基线](https://m3.material.io/components/navigation-drawer/specs)；保留64dp首页、随窄屏缩小和使用整体平移是本项目建议。Material 当前页面也注明 Expressive 更新后推荐扩展导航轨；本稿引用抽屉基线作为尺寸先例，不将自定义滑盖描述为最新官方组件的强制方案。

| 量 | 左侧快捷区 | 右侧快捷区 |
| --- | --- | --- |
| 首页位移 | `x=+D×p` | `x=−D×p` |
| 遮罩透明度 | `alpha=0.32×p` | `alpha=0.32×p` |
| 快捷区本体 | 固定在首页下方左侧 | 固定在首页下方右侧 |

建议使用中性黑遮罩，最大不透明度32%。首页位移和遮罩共用同一个进度，松手收束、反向拖动和中途打断都同步变化。32%需在实际浅 / 深主题中核对可辨识度；它不是 Flutter 默认抽屉 scrim 数值。

## 7. 顶部收起 / 回展状态机

### 7.1 触发条件

“上拖 / 下拖”指手指方向。惯性阶段沿用发起它的有效纵向阅读方向；不单靠惯性时某一帧的 offset 符号判断意图。

| 事件 | 顶部结果 |
| --- | --- |
| 首次进入并完成定位 | 展开，沿 Q-040 |
| 展开时明确上拖阅读 | 逐步收起；收起距离见 §7.2建议 |
| 紧凑时同日下拖 | 保持紧凑，继续滚动时间轴 |
| 紧凑时下拖使浏览日期切换 | 展开，保持正在阅读的时间位置 |
| 下拖松手后惯性才跨日 | 同样展开；算同一次下拖 |
| 下拖跨日后继续下拖 | 保持展开，不用旧距离立即收回 |
| 上拖跨日 | 只更新浏览日期 / 统计，不因此展开 |
| 展开后下一次明确上拖 | 开始新一次收起距离累计 |
| 箭头 / 日历 / 返回今天成功跳转 | 展开，沿现行显式导航合同 |
| 显式跳转读取失败 | 保留旧窗口、日期、位置和顶部状态，重试原目标 |
| 头部高度补偿 / 回弹 / 数据刷新 / 程序恢复位置 | 不作为下拖跨日，不触发新的收放 |
| 详情 / 概览 / 复盘返回，或普通开关快捷区 | 保留离开前状态 |

“仅下拖跨日时展开”约束连续阅读中的自动回展；明确点击导航成功后的展开继续沿[Q-040](../domain/OPEN_QUESTIONS.md#q-040)。横滑不再是显式切日入口。

下拖的惯性归属保持到这次阅读滚动停止或被新手势 / 显式操作接管。自动扩展查询窗口只是为继续阅读提供数据；真正来自下拖阅读的跨日可以回展，只有扩窗后的坐标补偿不能回展。

### 7.2 收起距离与中途松手

建议先沿用熟悉的量级：一次有效上拖阅读累计40dp后开始收起，120dp时完全收起。区别在于距离来自**这次上拖阅读**，不再来自进入日时的绝对阅读起点；旧32dp“回到起点即展开”规则取消。

建议手势期间顶部进度直接跟随有效阅读距离；跨过40dp开始收起后，若松手或反向变成下拖，则收束为紧凑，避免永久停在半高状态或因同日下拖自动回展。未超过40dp则保持展开。这是本稿的过渡处理建议，40 / 120dp和收束策略需要一起做真机验证。

### 7.3 保持时间锚点与日期稳定

顶部展开改变时间轴视口高度时，保留当前阅读时刻在屏幕上的位置。锚点使用时间 instant、所属日期及视口相对位置，不保存一个会因布局变化失效的裸 scroll offset；重复本地时分也不能被误认成同一时刻。

跨日沿现有连续轴的规则判定：视口顶边越过日分隔后提交对应浏览日期；不因页面中间露出另一日的标题就提前切日。回展事件取自补偿前已经提交的真实浏览日期变化。同一次跨日只启动一次回展；回展造成的尺寸变化与恢复回调不能再改写日期、再触发回展或立即收起。高速连续跨过多日时合并到最新日期，不排队播放每一天的日期 / 统计动画。

## 8. 提醒卡边界

**待确认：** 用户说“提醒卡不影响”，但当前实现会随顶部收起而隐藏。需要明确是让卡片独立于顶部显隐，还是保持现有联动、只不改内容与触发规则。该问题已询问；本稿不根据预选选项作答。

两种候选只影响布局：

| 候选 | 展开顶部 | 紧凑顶部 | 浏览空间 |
| --- | --- | --- | --- |
| A：卡片独立于顶部 | 按提醒开关与建议结果显示 | 同样按提醒开关与建议结果显示 | 紧凑时仍保留卡片所占高度 |
| B：保留现有联动 | 按提醒开关与建议结果显示 | 随顶部隐藏，退出触控 / 读屏 | 紧凑时释放卡片高度 |

无论选择哪项，卡片都属于整体移动的首页表面。提醒优先级、时窗、历史 / 未来日问候、设置开关及进入 / 返回 / 恢复前台更新继续沿[Q-028](../domain/OPEN_QUESTIONS.md#q-028) / [Q-029](../domain/OPEN_QUESTIONS.md#q-029)，不因开盖、收盖、上拖或下拖新增定时刷新或重复提示。

## 9. 日期导航与今天上限

### 9.1 普通浏览

普通纵向浏览和前后日箭头最多到实际今天。今天的后一天按钮禁用，并提供相应语义说明；时间轴在今天终端停止，不通过弹性回弹进入明天或让顶部日期短暂闪到未来。达到边界保留平台正常滚动反馈，不虚构未来内容。

过去日期可连续阅读或用箭头跳转；点击日期始终打开日历。横向拖动只开合快捷区。顶部日期、极简 / 完整统计以及快捷区的当日入口都以同一已提交浏览日期为准。

### 9.2 主动选择未来

日历可以主动选择未来，返回今天仍可用。未来日按既有领域合同处理：对账窗口为空，不虚构Gap或补账提示；用户合法的未来正区间事实能力沿 Q-016，不把首页导航上限变成输入禁令。[Q-009](../domain/OPEN_QUESTIONS.md#q-009)、[Q-016](../domain/OPEN_QUESTIONS.md#q-016)、[Q-040](../domain/OPEN_QUESTIONS.md#q-040)

**待确认：** 手选未来后，普通导航是否临时允许浏览到所选日期、仅能向今天回退，或完全禁用前后日按钮。三个候选已询问，不能自动采用其中任意一个。

建议方案是把成功手选的未来日期作为本次浏览上限，返回今天成功后恢复今天上限。这样从未来日往前看后仍能回到刚才选中的日期。只有未来读取成功并完成定位才建立临时上限；失败不能扩大范围。这条仍是待选择建议。

### 9.3 跳转、返回与刷新

今天默认靠近同次投影的当前时刻；历史日靠近第一条正式事实（含Unknown / Sleep），无事实历史日从自然日起点；未来日不虚构Gap，沿 Q-040。箭头、日历和返回今天跳转都在读取成功后提交新日期 / 窗口与定位，不先显示新日期配旧统计。

读取失败保留旧阅读窗口与顶部状态，允许重试原目标。详情、概览和复盘返回恢复原日期与阅读位置。跨午夜跟随、恢复前台重读与投影一致性沿 HOME-NAV-02；新导航上限必须使用同一实际今天，不从预览截图或旧加载结果推算。

## 10. 设置：快捷区位置

设置 > 界面设置增加“快捷区位置”，只有左侧 / 右侧两个选项。默认左侧来自用户明确决定，不由平台或当前语言悄悄改变。设置同时调整快捷区所在侧、打开 / 关闭方向、菜单按钮及返回今天按钮位置。

建议使用一行当前值摘要，点击进入单选设置；附简短预览“向右滑打开”或“向左滑打开”。选择成功后持久化为本机界面偏好。回到首页时快捷区处于关闭状态，新位置生效，原浏览日期、阅读锚点和顶部状态保留；不重建正式事实或重置记录输入。

保存失败保留原已生效位置，明确反馈并可重试，不显示“已保存”却在重启后回退。菜单打开进度与阅读位置是临时presentation状态，不持久化为新领域事实。设置控制方式及关闭后生效的交接属于本稿建议；已有本机偏好存储可承接，未来实施不因此新增通用框架。

## 11. 动画节奏

手势动画使用实时位置；松手后用可中断的收束。首页移动、遮罩、菜单项可操作性同一进度驱动，不能分别排队执行。Material 当前动效指导优先使用可带初速度、可重定向的弹簧，并推荐功能性产品使用较少弹跳的 Standard 风格。[Material 动效机制](https://m3.material.io/styles/motion/overview/how-it-works)、[当前动效规格](https://m3.material.io/styles/motion/overview/specs)

| 动效 | 建议首版参数 | 说明 |
| --- | --- | --- |
| 手指拖动滑盖 | 实时跟手，无固定缓动时长 | 识别后1:1映射有效横向位移，范围夹在0–D |
| 点菜单 / 点遮罩 / 松手收束 | 常见距离视觉目标约250–300ms | 不是每次强制同样时长；初速度、剩余距离和中断影响实际时间 |
| 滑盖弹簧 | mass=1，stiffness=700，dampingRatio=1 | 首版建议使用临界阻尼，减少端点过冲 |
| 遮罩 | 最大32%，随 `p` 连续变化 | 不另起独立延迟或弹簧 |
| 上拖收起顶部 | 跟随有效阅读进度 | 稳定端点收束建议200ms；不反复重启动画 |
| 下拖跨日回展 | 200ms | 建议标准曲线 `cubic(0.2,0,0,1)`，同时补偿时间锚点 |
| 日期 / 时长更新 | 150ms轻淡入淡出 | 日期与统计同步提交；不变的内容不重播，时长不逐个滚数 |
| 连续阅读跨日 | 时间轴继续原滚动 | 不整页淡出、重新定位或出现空白刷新帧 |

700的弹簧刚度参考 Material Android 的 default spatial 参数；该默认阻尼比为0.9，本稿调到1以获得临界阻尼。Flutter 提供阻尼比构造器，1表示临界阻尼。这是参数改编，不是直接照搬默认组件。[Material Android Motion](https://github.com/material-components/material-components-android/blob/master/docs/theming/Motion.md)、[Flutter SpringDescription](https://api.flutter.dev/flutter/physics/SpringDescription/SpringDescription.withDampingRatio.html)

Flutter 抽屉源码的控制器基准时长约246ms，但 open / close 使用 fling，实际结束时间由弹簧与速度决定；不能把基准值当成固定时长保证。250–300ms是本项目的常见场景体验目标。[Flutter 抽屉源码](https://github.com/flutter/flutter/blob/master/packages/flutter/lib/src/material/drawer.dart)、[AnimationController.fling](https://api.flutter.dev/flutter/animation/AnimationController/fling.html)

150 / 200 / 250 / 300ms和标准曲线可在 Material 旧版时长 / 缓动 token 中找到量级参考；当前 Expressive 弹簧及其曲线转换时间不是同一套固定值。本稿仅将短时长用于文字与布局收束建议，不宣称250–300ms是最新 Material 默认空间动画。[旧版 token 参考](https://m3.material.io/styles/motion/easing-and-duration/tokens-specs)

系统要求减少 / 关闭动画时，取消装饰性弹簧与淡入淡出，直接应用目标布局和焦点；手动拖动仍可直接改变位置。实施时按目标 Flutter SDK核对 Android `disableAnimations` 与 iOS `reduceMotion` 等平台信号，不能只检查一个属性就宣称所有平台通过。[Flutter 动画偏好说明](https://api.flutter.dev/flutter/widgets/MediaQueryData/disableAnimations.html)

## 12. 关键连续操作

| 场景 | 操作链与结果 |
| --- | --- |
| 阅读历史日及相邻日 | 上拖阅读并收起顶部 → 上拖跨日仍紧凑 → 随后同日下拖保持紧凑 → 下拖跨日时展开 |
| 快速回看后停下 | 上拖后松手，惯性跨日只更新日期 → 停在紧凑态，时间位置不因跨日重置 |
| 快速下拖跨日 | 紧凑态下拖后松手 → 惯性进入另一日 → 200ms建议回展，继续原阅读，不因补偿马上收起 |
| 浏览历史时打开概览 | 按设置方向开盖 → 标明历史日期 → 点当日概览 → 概览带同一天 → 返回首页恢复历史时间位置 |
| 从快捷区返回今天 | 历史 / 未来日开盖 → 返回今天 → 成功后靠近当前时间、顶部展开、返回今天入口消失 |
| 菜单右置 | 设置选右侧 → 回首页菜单在右上、返回今天在左侧 → 向左开盖 → 向右收盖 |
| 误触与取消 | 斜向纵滑由时间轴处理；不足条件的横拖回到端点；不触发起手位置上的记录或Gap补记 |
| 操作时数据读取失败 | 原窗口、日期、统计、阅读与顶部状态保留 → 明确失败并允许重试原目标 |

上表方向指手指方向；具体起始时刻和一屏可见小时数按实际布局，不能硬写每次拖动都会跨日。

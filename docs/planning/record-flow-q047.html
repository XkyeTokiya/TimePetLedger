验证清单

  • 记录活动、保存后理解层、时间选择都以底部面板呈现；记录面板不占整页、没有大片空白。
  • 记录面板顶部直接显示开始 / 结束时间，点时间打开时分滚轮、点日期打开日历；无效时间不应用。
  • “补充说明”与“下次从哪儿接上”默认折叠成一行，点按才展开编辑框；已填写内容折叠时可见摘要。
  • 保存后理解层是底部浮层，不推动时间轴；× 关闭后可继续操作账本，不自动重复出现。
  • 状态问题内部没有“跳过”按钮；“暂时说不清”是出口且不写入任何状态。
  • 必选边界：状态未回答时可直接去记下一笔或点其他 Gap，不拦截；之后可从详情补充。
  • 事实保存失败保留输入并可直接重试；理解层保存失败不回滚事实、卡片内可重试。
  • 键盘占位开启时，记录面板抬升到键盘上方；320 / 360 / 412 宽度与 1 / 1.5 / 2 倍文字下主要动作可达。

边界

  • 视觉按现行应用默认 Material 3 近似（紫、系统字体、M3 组件形状）；暖纸主题不在此原型。
  • 时间轴按 72px / 小时的比例示意；短段聚合、日期分组、拖拽滚动等正式行为未复刻。
  • 滚轮与日历为 HTML 交互复刻，只验证流程，不代表 Flutter 组件、无键盘或读屏验收。
  • 本地内存模拟，不写数据库；睡眠、复盘、目标管理、删除不在本原型范围。

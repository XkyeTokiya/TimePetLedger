### 摘要的第一版结构

1. 一天时间构成：当日睡眠切片、已知活动、想不起来（Unknown）、尚未记录（Gap）。中心显示已交代时长，图例列实际时长，点击查看所选部分占比；完整睡眠另作补充，不混用完整时长和当日切片。
2. 目标时间构成：各目标占全部目标相关时间的比例，中心显示目标相关总时长。下面按目标展开推进 / 卡住 / 恢复 / 未标记节奏；单列全局恢复，让没有关联目标的恢复也可见。
3. 历史日期按完整本地自然日，今天按00:00至当前时刻；未来部分不计为Gap。自然日不写死为1440分钟，沿既有日界线合同计算。
4. 无目标记录展示空态，不造评分或效率判断。事实与可选节奏解释仍分开；Unknown属于已交代，Gap是派生缺口。

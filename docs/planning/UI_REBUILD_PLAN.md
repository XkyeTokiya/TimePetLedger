## 已确认的设计边界

- 用户进一步明确：首页也纳入界面层重建，以已确认首页原型为视觉基准重新实现，不以现有Widget树、布局或组件限制设计。此前“保持现有首页不动”的边界撤销；不是重新发明首页方向。仍禁止未经确认新增标题栏目标入口；此前1–6项去重及全应用隐藏“约”的最新决定覆盖旧原型对应细节。
- 活动无草稿时默认记得，已有事实/草稿恢复原选择，不自动弹键盘。Unknown切换不清原文，仍能关联目标和节奏。
- 全应用时间/时长数值不显示“约”；保留精度数据及编辑准确/大约选择。高级显示开关仅后续候选。
- 时间底部弹层直接编辑双端，时钟直达时分选择且保留日期，日期可手填；取消不应用，应用才进草稿，精度独立。
- 目标/节奏展开互斥，错误定位也必须遵守。切换区域不清输入。
- 目标轻量选择/创建，不跳完整管理页完成短操作；创建返回关联，读取失败仍保留关联意图。
- 节奏内部不嵌套折叠，标签可不选、再次点击取消，无“不填写/不标记”选项；当前状态细节直接展示，接续点在细节后；无清空原因按钮。
- 不加入保存时缺少目标/节奏提醒，不把可选解释变必填，不增加评分或自动解释。
- 原型作为视觉参考；与上述最新决定矛盾的旧文案和路径不继承。

## 完整活动样板矩阵

独立开发入口、固定时钟与状态；不写正式库，不把模拟成功称为真实保存。样板必须使用后续正式组件，而不是复制一份展示代码。

| 状态 | 必须覆盖 |
| --- | --- |
| 新建/Gap/更正 | 上下文、默认值、已有内容、草稿恢复 |
| 记忆状态 | 切换保留原文、长中文、Unknown合法归属 |
| 时间 | 双端/跨日/独立精度、手填日期、时钟、键盘、取消/应用、无效输入 |
| 目标 | 空列表、选择、长名/同名ID、归档引用、创建/取消、加载及写入失败、创建成功刷新失败 |
| 节奏 | 未选/推进/卡住/恢复、再点取消、原因/恢复标签、接续点顺序、切换保留内容 |
| 展开/焦点 | 互斥、错误区域转移、补充摘要、输入可达 |
| 保存 | 防重复、冲突、失败重试、正式成功后清理/刷新失败只收尾 |
| 返回 | 取消不应用、离开flush失败不静默退出、明确放弃草稿 |

尺寸320/360/412，文字比例1/1.5/2，短窗口和IME；不通过缩字/裁切隐藏问题。精简态、目标态、卡住态、时间键盘态、冲突态形成对照板。真实IME与模拟截图分别标记。

## 六屏区块树与显隐合同

各屏共同外层：系统区 → 标题栏 → 可滚动正文 → 保存条 → 必要附件/IME → 安全区。V04中附件的确切位置以原型为准（保存条后、IME前）。

| 屏号 | 正文从上到下 | 显隐与并排 |
| --- | --- | --- |
| V01 | 日期/补记上下文 → 活动主输入 → 记得/想不起来组 → 时间+时长+修改 → 目标/节奏 → 补充内容 | 目标与节奏360宽并排；补充折叠；无目标/节奏默认值；Unknown隐藏标题输入但保留原文 |
| V02 | 完整睡眠上下文 → 主睡眠/小睡组 → 入睡卡 → 醒来卡 → 完整时长 → 调整双端 → 备注 | 每张端点卡整体可触；开始近似、结束准确独立；备注无值只留展开入口 |
| V03 | 复盘日期/修改 → 下一自然日提示 → 第一步 → 再写几句/目标 → 当日事实 | 再写几句与目标并排；概述/反思和事实折叠；不常驻写作附件 |
| V04 | 第一步摘要 → 概述 → 反思 → 当日事实 | 同一复盘页展开并滚到概述；概述聚焦；附件切焦点/收键盘，不提交 |
| V05 | 完整睡眠上下文 → 入睡日期/时间/精度 → 醒来日期/时间/精度 → 手动输入 → 完整时长 | 两端同层；手动输入次级；取消丢局部副本，应用才写草稿 |
| V06 | 冲突对象/区间/调整提示 → 原活动输入 → 记忆状态 → 修改后时间+时长 → 目标/节奏 → 补充内容 | 冲突在正文前；输入保留；目标/节奏并排；技术ID不得占首层；不自动覆盖散步 |

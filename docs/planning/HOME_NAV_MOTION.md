# HOME-NAV-03 · 首页切换动效与闪烁修复

2026-10-07。用户在HOME-NAV-02后反馈“当前缺少动效，切换的时候很多数字和文字还会闪烁”，本轮继续修复首页切日、日期与覆盖数值的表现。

## 方案与范围

1. 显式切日只定位新日期，取消同时执行旧锚点恢复；定位完成前不从临时滚动位置反写焦点。普通刷新与窗口扩展继续恢复阅读锚点。
2. 时间轴按窗口末日切换，保留退出视图的只读投影快照；新视图完成定位后显示，约220ms按切日方向左右平移。新旧页面保持相邻且不透明，避免文字重影。退出视图不响应操作、不参与焦点更新或读屏。相同窗口刷新保留原State及阅读位置。
3. 日期、星期与时长采用约160ms的裁剪上下切换，只在显示内容改变时触发；日期与数值固定行高，标签和操作按钮保持稳定。建议卡内容同样加入过渡。时长始终显示真实值，不生成中间统计值。
4. 使用Flutter既有动效组件，无新增依赖。系统disableAnimations开启时立即完成，保持单一当前语义与触控入口。

实现限定首页presentation及相关测试 / 交接文档，保持HOME-NAV-02的失败重试、快速连续切日、跨午夜跟随、历史日期、独立页与草稿合同。领域事实、统计公式、数据库、摘要 / 复盘内容及其他编辑页动效不在本轮范围。

## 验收

- 切日成功后的逐帧焦点通知只包含目标日期，不短暂回到旧日或其他中间日；重复切换只保留最新目标。
- 动画中新旧时间轴保持相邻，数字与文字连续可见；目标轴完成定位后才参与绘制及操作，退出内容语义与操作隔离。
- 刷新、装载更早日期、尺寸变化与返回页面保留阅读位置；同值刷新不触发数值动画；失败保留旧内容。
- 前进 / 后退均有方向反馈；快速重复切日、跨年、大字、窄屏无布局异常；关闭动画后直接定位到目标，不等待动画时长。
- 格式、静态分析、相关测试通过；全量失败集合对比前轮103项既存失败，报告平台未实测限制。

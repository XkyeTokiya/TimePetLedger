## 2. 整体结构

两个一级目的地：回看、复盘；中央“＋记录一笔”为创建动作。七类全屏页：日账本、复盘读取、当日摘要、目标管理、活动编辑、睡眠编辑、复盘编辑。详情、目标选择、日期选择、说明和确认使用对应轻量层，不各自增加根导航。

实现验收先看：主任务是否突出、区块顺序、并排关系、信息密度、显隐、正文与操作区关系；其次看字号、圆角和尺寸。禁止以“按钮都有、字段没丢”代替原型还原。

## 3. 三编辑页的目标结构

### 活动：V01 / V06

从上到下：
1. 标题栏：返回、补记活动/记录活动/更正记录、更多。
2. 日期与入口上下文的轻量一行。
3. 活动主输入，支持换行与完整编辑。
4. “记得 / 想不起来”同一选择区。
5. 紧凑时间区间、时长、修改入口；主层不铺开双端日期和精度选项。
6. **目标与节奏并排**；已填显示当前值，长值/大字才按可用宽度换行。
7. 补充内容展开入口；有内容展示摘要。
8. 正文之外的保存条：真实草稿状态、保存到账本/保存更正。

冲突态V06在正文前显示具体冲突对象、区间和调整入口，保留输入；不得把技术ID与长篇说明作为首层主要信息。确需身份区分时提供次级可读入口。

### 睡眠：V02 / V05

从上到下：日期与“完整睡眠”上下文、主睡眠/小睡同组选择、入睡卡、醒来卡、完整时长、调整双端时间入口、备注展开、保存条。

每张卡是一个整体触控区域：上部端点名称和日期，下部时间；两端精度独立，不重复堆叠完整时间字符串。新建未填时显示选择入口，不推断类型、时间或精度。

V05为同一个双端时间编辑层：入睡与醒来各自日期、时间、精度；手动输入次级可达。层内保留临时副本，应用才进入草稿，返回/取消不应用。允许保留未完成原文，正式有效性由既有校验承担。

### 复盘：V03 / V04

从上到下：复盘日期与修改日期入口、下一自然日第一步提示、第一步主输入、**再写几句与目标并排**、当日事实折叠入口、保存条。

“再写几句”在同页展开概述和反思并聚焦概述。连续写作态保留第一步上下文，正文自然滚动；上一项/下一项/完成切换焦点或收起键盘，不提交。附件栏按连续写作需要出现，不能无条件侵占最简首屏。

读取事实不改写输入；显式继续写作恢复原字段和选择范围。改日期沿用唯一性检查，取消不改变草稿；碰撞不覆盖已存复盘。

## 4. 信息与间距规则

- 用户后续决定：新建活动无草稿时默认选择“记得”，移除要求选择记忆状态的说明；已存草稿和事实恢复原选择。活动时间编辑直接展示两端可编辑输入，单端选择器仅为辅助入口。

- 用户后续明确校准：活动编辑页时间摘要端点不重复添加“约”，例如`10:30 → 11:15`；仅时长显示`约45分钟`。这是展示变更，独立起止精度继续保存并在时间编辑层选择，不改变近似计算及冲突规则。此决定覆盖HTML中两端分别带“约”的活动摘要示例。

- 页面负责区块之间的间距；组件只负责内部间距。相邻组件不得各自添加外部留白造成双倍空隙。
- 沿用HTML基准：左右16，主区块间16；细节按原型使用8/12，独立段落24。每屏交付须注明区块边界，而不是任意插入SizedBox凑位置。
- 同组控件共享对齐线和布局容器。常态360宽不得把设计中并排入口无理由拆为两行。
- 标准首屏不使用Expanded/Spacer填充正文空白；仅正文滚动区和底部操作区承担剩余空间分配。
- 保存条、附件栏、安全区只各计算一次；Scaffold与嵌套SafeArea不得重复扣除inset。
- 不常驻“可选/必填”、技术说明、未填写占位堆栈。有效内容不能因次级入口而降为禁用对比度。
- 错误自动展开对应字段，并提供可读文字和恢复入口；折叠不清数据。
- 颜色通过共享ThemeData/ColorScheme消费，最后统一调整。布局返工不追加局部硬编码配色。

## 5. 主页、阅读与管理

主页延续已认可的连续时间轴、全天时间条和底栏。已确认R06睡眠详情作为现有基准；活动详情按R04，而不是套用睡眠字段列表。Unknown仍是事实，Gap仍是待处理区间。

阅读管理按R01–R09：复盘先呈现用户文字和下一步，摘要按睡眠/目标时间阅读，统计细分展开；目标管理是轻量列表。分别核验空态、读取失败、归档引用及删除反馈，不把正常状态图当作全部交付。

## 6. 保留的工程合同

- 不修改domain/application/data、数据库、投影算法及产品规则；不新增依赖。
- 三表单保留各自controller所有权、flush、离开和返回值，不用统一保存组件统一业务逻辑。
- 未提交草稿写入失败留在原页；已提交清理/重读失败只能收尾，禁止重复正式提交。
- 睡眠按完整源记录更正和删除；跨日事实不拆分。复盘删除针对原身份与原日期，不针对当前未保存日期。
- Goal仅为时间归属；节奏是解释；下一步与接续点不混同。
- 保留现有未提交工作，不大范围重置、重构或机械改写测试。

## 7. 交付与验收方法

### 同条件对照

每屏使用HTML指定日期、记录、精度、入口和状态，以360×800、1倍文字为主基准。对照材料同时列出HTML与Flutter截图、对应屏号、数据、路由、平台inset和键盘状态。

正常保存样例必须接入真实可用服务；不能以禁用按钮夹具代替正常态。V02必须是更正，V06必须有真实冲突返回。模拟IME与真实系统键盘分别标注，不伪装为设备截图。

### 分开记录三类结果

1. **原型还原自查**：区块顺序、并排关系、信息层级、留白、折叠和操作位置逐项匹配；偏差列明原因，未经确认不擅自替代。
2. **工程验证**：格式、分析、相关真实仓储回归、布局/焦点/取消/错误恢复测试；旧测试仅迁移入口，不删除业务断言。
3. **用户视觉验收与平台验收**：分别记录结论；用户未确认不能标视觉通过，缺设备不能标平台通过。

适配覆盖320/360/412、1/1.5/2倍文字、长输入及极短窗口；允许合理换行和滚动，不缩字硬塞。实机另测中文候选栏、系统返回、旋转、安全区；Web另测Tab、Enter换行、Escape与模态焦点返回。

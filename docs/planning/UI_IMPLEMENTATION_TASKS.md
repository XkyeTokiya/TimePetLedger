## PAGE-T01 — 还原清单与视觉夹具

- **Depends on：** 用户审阅本设计与任务安排，明确授权执行。
- **来源：** 编辑HTML V01–V06、输入校准、设计文档§3–7。
- **范围：** 每屏区块树、显隐/并排关系、间距归属表；六屏可重现数据和路由。沿用真实服务/仓储，固定时间注入，正式库不混入演示数据。
- **Out of scope：** 页面全面重写、调色、新产品规则。
- **Acceptance criteria：** V01补记两端近似；V02完整跨日睡眠更正；V03合法第一步可保存；V04展开写作；V05取消不应用；V06真实冲突且输入保留。每屏正常/失败状态真实，按钮不因缺服务被禁用。
- **Validation：** 运行夹具冒烟，核查总量/精度/源ID；生成同条件截图与原型索引。截图占位与实机状态明确标注。
- **交付：** 对照清单、夹具文件、运行命令和截图；不把夹具就绪视为页面通过。

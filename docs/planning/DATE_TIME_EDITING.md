# TIME-02 — 日期与时间独立修改

日期：2026-10-07。依据：用户补全授权、源提案后续决定、Q-038。实现已交付；验证及平台限制见[报告](../reports/TIME-02_DATE_TIME_EDITING_REPORT.md)。本任务不扩展时间预测算法，不实施Q-037其余候选。

## 简洁设计

- 开始日期、开始时间、结束日期、结束时间是四个独立入口。点击日期直接开日历，点击时间直接开现有中文时分滚轮；确定后立即更新该字段并关闭，取消保持原值。
- 打开定位当前输入；没有值时使用入口日期与12:00作为可改初值，不因打开而写入。改日期保留时分、秒和毫秒，改时分保留日期、秒和毫秒；另一端和精度保持。当地不存在的日期时间提示重选，不静默归一化。
- 手动改时分不自动换日。跨夜 / 跨年通过对应日期字段操作；正区间和跨事实原子不重叠校验照旧。独立字段允许暂时不合法，整笔提交仍校验。
- 进入新建 / 补记时的自动起止初始化沿已有实现，和本次字段编辑分开。时长正推 / 反推保留，整笔提交与草稿流程保留。
- 页面整体布局、主题与其他功能保留；日期文本变为可点击。当前活动 / 睡眠不增加精度选项，旧表单已有精度能力保留，不迁移旧事实。

## 覆盖入口

| 位置 | 修改与核查 |
| --- | --- |
| 当前活动新建、补记、更正 | 四字段独立；日期空值也有入口；原时间接日期调用移除 |
| 当前睡眠新建、更正 | 拆开同一行的日期 / 时分点击；保留左日期右时间样式 |
| 保留的RecordingForm、SleepForm、GuidedRecordingPage、ActivityEditor | 四字段替代总时间编辑面板；保留标题、可选内容、精度、失败与保存流程 |
| 首页、日账本、嵌入复盘 | 原日期直达日历路径已符合，继续保留 |
| 复盘表单、独立复盘上下文、基础摘要 | 日期字段直达既有账本日历，取消不更新；清理原文本输入控制器 / 无效日期临时状态 |
| 设置的睡眠 / 复盘提醒时点 | 直接打开同一中文滚轮，保留当前偏好初值、取消与持久化规则 |
| 目标、详情与统计 | 日期为事实展示或既有日期范围选择，无额外日期编辑面板 |

删除旧双端面板activity_time_sheet、guided_recording_time_sheet、editor_time_page及旧手工时间对话框，清理相关展开状态、焦点节点和路由。TIME-01已移除生产activity/activity_time_sheet，本轮不恢复。

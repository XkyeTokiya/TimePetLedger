4. 信息层级与操作路径

对象默认首层详情 / 编辑 / 删除
普通事实起止、标题、时长；有值才出现目标与节奏；不显示“已知”点击整行打开只读底部详情面板，含完整标题、源日期与独立精度、目标及归档状态、节奏、备注、接续点及当前状态适用的原因/恢复细节。面板显式“编辑完整记录”“删除记录”，不是长按隐藏菜单。标题不截断；详情可滚动。
Unknown固定“想不起来”+“已交代”，有原title时另显示其文本，不丢失可见说明同一详情路径，保留原有目标/解释/备注；允许更正为known，绝不作为待补Gap催促。
睡眠主睡眠/小睡、当日时长；跨日标记及完整时长原始入睡/醒来与各自“约”、完整日期在详情，不用“约区间”污染准确端点。编辑始终传源ID。详情删除入口沿用既有睡眠编辑删除流程；如需进入原编辑页执行删除，不另造删除服务或跳过既有确认。
Gap起止、尚未记录、时长、64×48补记整行及补记均直接进入原Gap草稿，保持建议区间可修改；标记未知仍经原表单正式保存。Gap没有详情编辑/删除，也不作为实体。
完整睡眠汇总列表末尾48高折叠入口“完整睡眠 · 按醒来日期”展开原按醒来日期汇总，保留主睡眠/小睡分组、每段、合计及更正/删除。即使该日没有相交切片仍能访问，不能从时间轴切片重新推算。
日期与维护前后日、点日期、顶栏更多日期选择层：日历/手动输入/今天，说明跟随或固定模式；更多：刷新账本、当日摘要、目标管理、时间分布说明。概览ⓘ与更多内说明打开同一窗口/图例内容。刷新保留显式可达，不依赖手势。
底栏与草稿回看 / ＋记录一笔 / 复盘创建打开原活动/睡眠选择。草稿沿用newEntry/gap/edit原上下文恢复；复盘共享选日；返回保留既有阅读锚点。无新增草稿中心，无虚构“复盘已保存”卡片。

详情面板有48×48关闭目标，支持系统返回；关闭回原行原位置。点击整行的无障碍名称含事实、时段、时长及“查看详情”，有焦点态；不可要求仅凭颜色或长按发现。对长内容、较矮窗口使用可滚动面板，操作区不会被系统安全区遮住。HTML是静态可滚动视觉规格，按钮不连接业务；交互路径以本表为合同。

5. 关键状态与窄屏规则

  • 正常成功：不占一行显示“日账本已读取”。首次加载显示局部加载状态；刷新时若保留旧视图须明确“正在更新”，不能把旧投影标为新日期数据。
  • 读取失败：概览上方紧凑错误区+48高“重试读取”；无有效数据时不显示虚构0值。若现有controller保留旧视图，明确“未更新”，不改变controller语义。
  • 删除：沿用原确认及完整事实删除语义。删除未提交失败与已提交但草稿清理/重读失败分开；后者必须保留“继续清理并刷新”。错误不能藏在已关闭的详情面板内，主页保留可见恢复区域；沿用busy互斥。
  • 首次睡眠确认、已有草稿恢复、主睡眠检查失败及重试保留原触发条件；仅在有真实状态时出现。草稿不进入概览或时间轴。保存、取消、系统返回、路由返回刷新均沿用原合同。
  • 今天：概览显示“截至 HH:mm”，额外占一行时允许首条下移；当前时刻以外是尚未发生，不画成Gap。历史日完整窗口在说明层。未来日显示“未来日期，暂无对账窗口”，不催补记，不新增未来事实展示政策。
  • 空数据：窗口非空时显示“此账本窗口尚无正式记录”及一个完整Gap、可补记；窗口为空则无Gap。完整睡眠缺失表达为“尚未记录主睡眠/小睡”，不是睡眠为0。
  • 320/412宽与1.5/2.0文字缩放：左右16，时间列继续按“约00:00”测量，轨道连续。优先给标题整行：横排剩余标题宽不足4个当前字号汉字时，时长换至下一行左对齐，不继续挤压。长标题完整换行；目标标签可换行；Gap补记保持48目标并必要时独立成行。
  • 统计文字放不下时自然换行或上下排列，不能用FittedBox缩字；不固守首条y264。日期大字时允许两行与增高。底栏中央目标至少48高，按缩放增高或图标/文字换行；滚动区重新扣除实际底栏和inset。
  • 端点“约”仅按原端点/投影精度显示；切片、Gap、汇总分别继承近似，不整页统一加“约”。自然日按真实instant与设备时区，保留夏令时重复刻度offset语义，24:00辅助语义说明为次日00:00。

# 方案三 UI-N 补充规格

2026-10-03（Asia/Shanghai）。本文件只交付 UI-T02 所需的视觉标注。

负责人在 UI-T02 执行期间明确选择「采纳草案并继续 UI-T02（推荐）」，采纳了[仓库外最小视觉草案](/home/tokiya/.codex/visualizations/2026/10/03/01a10254-baa9-7300-b570-bc4cd8fcd15a/ui-t02/visual-spec-proposal.md)。下列视觉部分状态为 **ADOPTED**；完整 UI-N、账本日期头 / 全天条、根导航、目的地切换、返回与滚动策略仍 **UNCONFIRMED**。本决定不满足 UI-T03 / UI-T04 的其余设计门槛。

依据为 [UI 改造计划](UI_DIRECTION_3_IMPLEMENTATION_PLAN.md)、选定图及[方案三设计说明](/home/tokiya/.codex/visualizations/2026/10/03/01a10149-6dc4-74b3-a366-ba5993adc555/timeledger-review/direction-3-design.md)。

| 用途 | 采用色值 |
| --- | --- |
| 页面背景 | #0E1C27 |
| 卡片、对话框、输入表面 | #172A3A |

| 错误 / 错误表面上的深字 | #FFB4AB / #3B1110 |

输入焦点为 2 逻辑像素青色轮廓，错误为错误轮廓及原错误文字；其他控件保留可见焦点状态。禁用继续由原控制逻辑决定。等待保留 CircularProgressIndicator 与原保存状态，不新增消息、重试、清库或重置动作。

使用系统字体和 Material 文字层级；时间轴维持时间 13、标题 17、时长 14、辅助信息 13 逻辑字号与原布局，文字随系统缩放。时间列沿用 UI-T01 按字体与缩放测量的统一宽度，最低 54；不固定大字宽度。常规交互目标至少 48×48 逻辑像素。圆角、控件间距沿用 Material 和 UI-T01 的既有结构。

三条应用入口共用同一 ThemeData。时间轴从 ThemeData 读取背景、主次颜色和睡眠 / Unknown 色，不保留第二套局部主题。不新增主题切换、字体包或依赖，不改页面结构、表单字段、回调、源事实身份、精度或存储生命周期。

实际渲染、文字缩放、控件状态、guideline 与截图验证记录在 UI-T02 交付报告；本规格的采纳本身不代表验证通过。

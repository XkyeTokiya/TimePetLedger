## 2. 设计目标与首页范围

让用户看懂当前阅读日期、时间的连续关系、已交代与尚未记录的区别，并直接处理某段时间。首页继续只承载账本；摘要、复盘、目标、设置沿既有侧边栏入口。

**已确定约束：** SleepSession 独立；Unknown 属于已交代事实；Gap 派生且不持久化；跨日事实保留完整身份和原区间；今天只对账到本次读取时刻；未来不产生补账提示。统计只描述事实，不出现完成率、效率评价或庆祝。起止精度与时长展示沿原合同，不追加“约”。

**推荐设计范围：** 双态顶部、账本状态条、固定比例日时间轴、四类事实状态、当前时刻标记、情境卡收起及无障碍适配。普通活动不按分类或节奏染成彩虹色；原有节奏与备注仍可在事实详情查看，不在本轮重设计 Rhythm。

首轮不做时间拖拽、未来日程安排、缩放手势、复杂 sticky hour、横屏双栏、摘要图表改版、记录表单改版、睡眠预测调整或新依赖。

## 3. 两种页面状态

### 3.1 初始状态：先确认阅读上下文

| 区域 | 推荐呈现 |
| --- | --- |
| 标题栏 | 菜单 + 日账本，沿现有入口 |
| 日期区 | 前一天 / 大日期 / 后一天；星期与今天 / 昨天关系默认在日期同行，宽度放不下时回退日期下方。日期可打开日历，箭头各自切日 |
| 回到今天 | 仅非今天显示浅色小按钮；当天没有该按钮，也不留其专属占位 |
| 账本状态 | 浅色圆角区域内两列：已交代、尚未记录；时长为主、占比条为辅 |
| 时间轴 | 独立主滚动区，日期分隔后是真实比例时间空间 |
| 情境卡 | 开关开启且已有可呈现建议 / 问候时显示，位于操作栏上方 |
| 操作栏 | 记录睡眠为 Outlined，记录一笔为 Filled，固定于安全区上方 |

推荐主日期约 42sp，砖红强调；标题沿主题约 20–24sp；辅助信息用现有字阶。复用 NotoSerifSC 400 / 600 和暖纸白、砖红语义，不复制图片纹理或新增装饰素材。

### 3.2 滚动状态：把空间留给账本

**用户决定：** 紧凑顶栏保留菜单、日期、前后一天，以及非今天的回到今天。收起时仍保留一条对应当前浏览日的**极简状态行：已交代 / 尚未记录及各自时长**，可以省掉比例条；展开时恢复大日期、完整状态块与提醒卡。情境卡收起后退出绘制、触控与读屏范围；两个记录入口始终可用。取消收起态状态行属于另一项产品取舍，不在本次决定内。

推荐紧凑顶部在**实测能容纳**菜单、标题、日期导航和回到今天时为单行。320 / 360 宽或文字放大时允许两行：第一行菜单 / 标题 / 回到今天，第二行日期导航。紧凑是减少重复和留白，不以缩小系统文字或挤掉关键操作实现。连续轴内保留日分隔；紧凑顶栏已经承担吸顶日期时，避免再叠一层同内容日期条。

### 3.3 双态状态机（用户决定）

本节为HOME-TIME实施时的历史合同，新回展规则见[HOME-INTERACTION-01 §7](HOME_INTERACTION_DESIGN.md#7-顶部收起--回展状态机)，不可据本节继续实现已被替代的交互。

只有两个稳定状态：**展开 / 收起**；40–120dp之间的布局进度是展开态下的过渡值，不新增第三种持久状态。阅读起点是“进入该日时视口顶边对应的日期 + 时刻”，同时保存该时刻在视口中的相对位置。内部时刻保留instant以区分重复本地时分；刷新或尺寸变化后依据新布局重算起点与距离，不能把旧像素offset当起点。

`d` 表示当前阅读位置离该起点的有效纵向几何距离，向更早 / 更晚阅读都使用绝对距离。它根据起点时刻的新布局坐标、当前视口及保存相对位置求得；窗口扩展、头部补偿、程序跳转与回弹不累计为用户位移。只有有效用户纵向阅读事件驱动下表中的距离转换。

| 当前状态 / 事件 | 条件 | 目标状态与布局 |
| --- | --- | --- |
| 展开 + 用户滚动 | `d ≤ 40dp` | 展开，收起进度0；40dp为起始边界 |
| 展开 + 用户滚动 | `40dp < d < 120dp` | 仍属展开，收起进度`(d−40)/80`；反向返回时按同一进度回退 |
| 展开 + 用户滚动 | `d ≥ 120dp` | 收起，进度1，锁定 |
| 收起 + 用户滚动 | `d > 32dp` | 保持收起；轻微反向滚动不回展 |
| 收起 + 用户滚动 | `d ≤ 32dp` | 回展，进度0 |
| 任意 + 显式切日成功并完成定位 | 箭头 / 横滑 / 日期选择 / 回到今天 | 重置该次阅读起点并展开 |
| 任意 + 显式切日读取失败 | 沿HOME-NAV-02 | 保留原状态、起点、窗口及阅读位置 |
| 任意 + 连续浏览跨日边界 | 未显式切日 | 不重设起点；已收起则保持收起 |
| 任意 + 程序定位 / 回弹 / 刷新 / 头部补偿 / 返回页面 | 包括窗口扩展与尺寸变化恢复 | 不触发状态转换；保留状态，必要时按新布局恢复锚点 |

`32dp < d < 40dp`为滞回死区：原来收起就保持收起，原来展开就保持展开。32dp回展与40dp开始收起的边界不可用同一个阈值代替。初次定位完成展示展开态；从详情 / 摘要 / 复盘返回保留离开前状态，返回本身不能回展。

页头变化时保留同一阅读时刻的屏幕位置，并隔离补偿回调，避免反写错误浏览日或反复收放。180–240ms端点收束仍是动效建议；手势过程跟随进度，不叠加排队尺寸动画。系统关闭动画时立即应用目标布局，导航与焦点合同不变。

## 4. 真实比例时间轴

### 4.1 时间与位置使用同一套几何

**用户决定：** 全轴基础比例固定 `p0 = 72dp / 小时`，第一版不提供用户可调设置。所有事实、Gap、节点、小时刻度、当前时刻线、命中与短段判定共用有效比例 `p = p0 × a11yFactor`。

`a11yFactor`默认1.0。只有320dp宽 + 2×系统文字实测中，本应可显示的状态词仍无法辨读时，才允许全轴统一提高，最高1.25；不是每档文字倍率自动放大，也不是逐块min-height。状态词按§4.4在<12dp块内主动省略，不因这一规定本身触发比例提高。具体启用证据与所用系数在平台验收记录，最高有效比例90dp / 小时。

选择72的理由是保留一天的形状和浏览效率：60dp / 小时时20分钟仅20dp，接近13sp / 1.5行高的19.5dp；96dp / 小时时8小时睡眠达768dp，超过基准时间轴视口。固定几何下2×文字不会使时间比例改变或让可见跨度自动减半；变化来自块内可容纳内容及页头 / 页脚占用。

以该日真实零点为 `t0`，有效比例为 `p`，则日区内：

```text
y(t) = (t - t0) / 3,600,000 × p
h([start,end)) = y(end) - y(start)
```

几何用真实毫秒，不用已舍入分钟，也不通过文字高度决定。自然日标题 / 分隔在时间空间之外。边框放在所属区间内部；最多使用内缩的细缝区分相邻块，不能逐块追加 margin 让下方时间漂移。

| 区间长度 | 72dp / 小时下的几何高度 |
| --- | ---: |
| 20 分钟 | 24dp |
| 40 分钟 | 48dp |
| 1 小时 | 72dp |
| 1 小时 20 分钟 | 96dp |
| 2 小时 | 144dp |

**仅作为360×800、1×文字、`a11yFactor=1.0`的规划基准：** 普通24小时日高1728dp；收起后若时间轴视口约600dp，则一天约2.9屏；展开态预计约6–7小时 / 屏，实际以最终页头、页脚和安全区测量为准。这不是所有设备通用承诺。23 / 25小时日仍用真实日长，不能一律1728dp。

08:00–10:00 应恰好跨过两个小时刻度；12:00–12:20 的末端距 12:00 是 24dp；13:00–14:20 的末端在 14:00 下方 24dp。图片里的 08:00–18:00 是示意，不要求 360×800 的屏幕同时塞下十小时。

### 4.2 刻度与事实边界

左侧标尺默认每小时显示 HH:mm；中间轨道与块起止严格对齐。必要时只补半小时短线。最后的真实午夜边界可显示 24:00，今天窗口末端显示本次投影时刻，不误写 24:00。

边界节点与开始点对齐，而不是与标题中心对齐。Gap 段轨道虚线、起点空心；事实段实体线与实心节点；相邻段共用一个边界位置，避免双节点叠画。

很长的Gap或事实可能比视口高。推荐其状态 / 标题保留在该块与视口交集内的可读位置，受真实块边界约束，不能只把文字放在已经滚出屏幕的块顶部；移动阅读标签不改变块高、刻度或端点，也不重复生成语义节点。

时区偏移变化时，几何仍按实际经过时长；重复 HH:mm 带偏移或重复提示，跳过时刻不画不存在的小时。不要每个自然日强制 24 个等长刻度。日期转换沿设备时间适配层，纯 domain 不读设备时区。

### 4.3 四种视觉语言

| 类型 | 推荐视觉 | 内容与动作 |
| --- | --- | --- |
| 普通活动 | 低饱和暖色实体填充、左强调边、实心节点 | 用户标题；空间足够时显示目标 / 用户备注。点击进入既有事实详情 |
| Sleep | 柔和蓝灰、实体填充、床 / 月亮图标 | 主睡眠 / 小睡与日内区间；跨日保留切片提示，完整原区间和时长在详情可读 |
| Unknown | 中性灰实体填充、问号、灰实心节点 | “想不起来”；空间足够时“已交代 · 记不清具体做了什么”。进入事实详情，不标“补记” |
| Gap | 无实色或极淡底、砖红虚线轮廓、空心节点、虚线轨道 | 明确“尚未记录”；直接进入已有 Gap 处理入口，沿现行初始化 |

Gap 砖红虚线是本轮局部视觉建议；当前全局 `HomePalette.gap` 是灰色。评审通过后再决定是否增加局部边框用途 token，不直接改全局 Gap 颜色影响摘要。普通活动不自动推断阅读 / 吃饭等类别图标，不新增分类系统。睡眠说明不自动评价“充足让人有精力”；优先使用事实或用户备注。

### 4.4 短时段、文字与点击区域

≥60 分钟通常可放时间范围、标题、时长及一行次要信息；30–60 分钟通常为紧凑内容；<30 分钟通常只放单行状态 / 标题。阈值是初始模板选择，最终还要测量可用宽高与系统文字尺寸，不能把这些阈值当成文字一定放得下的保证。

**用户决定：几何不动、命中不重叠、歧义不猜。** 不用逐条 `minHeight: 48/64` 撑大几何，不以透明重叠热区或最近邻猜测命中。

#### 真实矩形与端点

数据块命中限于其真实布局矩形，纵向映射回真实时间半开区间`[start,end)`；几何内缩的边框 / 装饰不改变所属时间。横向在数据矩形外不命中该块，轨道装饰不扩大相邻块热区。共享边界像素归起始时间更晚的那段；绘制与命中共用边界变换，不能各自舍入造成重叠。

日窗口起点包含，终点排除：`t = W.start`可命中第一段，`t = W.end`及之后不命中上一段。今天当前线和历史日24:00端点是标记，不生成补记目标；下一日数据区从自己的窗口起点独立命中，不能穿过日分隔线点击前 / 后日。W为空没有数据块命中。日分隔线、按钮、面板行和其他导航目标独立处理，不参与时间轴区间命中。极短的亚像素段也保留自身语义与键盘路径，不把它的时间并入邻段。

#### 32dp短段簇

按有效比例计算实际几何高度`h`。`h < 32dp`属于短段；连续、端点相接的短段组成簇，`h ≥ 32dp`的长段或日边界切断簇。32dp在基础比例下对应26分40秒，约27分钟；阈值始终按有效几何dp判断，不固化为整数分钟。

| 命中对象 | 指针激活行为 | 提示 |
| --- | --- | --- |
| `h ≥ 32dp`的段 | 直接进入该Gap补记 / 事实详情 | 普通入口反馈 |
| 仅1段的短段簇 | 直接进入该Gap补记 / 事实详情 | 不显示“选择”提示 |
| 至少2段的短段簇中任一真实段矩形 | 打开该簇“时段选择”面板 | 簇统一显示“选择”提示，不扩大或重叠数据热区 |

簇提示属于视觉辅助，必要时放入日轴辅助提示层，不能遮挡相邻独立目标；<12dp单段省略文字的规则不取消簇的选择提示。簇成员由同一已提交日投影确定，不跨长段、日边界或面板控件拼候选；面板打开期间如投影更新使成员失效，不能凭旧位置转入其他事实。

**无障碍例外明确记录：** 48×48仍是按钮、菜单、日期 / 时间选择器、面板行等标准控件的基线。比例时间轴数据块是连续数据可视化，采用32dp直接访问阈值；32–48dp普通段以及孤立更短段的指针目标可小于48dp，这是本次用户明确接受的例外，不是标准目标尺寸达标声明。每段仍有完整类型、范围、标题 / 状态、时长及操作语义、独立键盘焦点；簇不合并为单一语义节点，读屏 / 键盘不得依赖颜色或指针小热区。

Web hover和键盘焦点提前高亮当前对象并提示“直接查看 / 补记”还是“打开时段选择”；标准焦点激活沿对应入口规则，无需精确指针定位。选择面板提供完整内容与逐项访问路径。

#### 面板与内容密度

“时段选择”采用Material 3底部面板，各行≥48dp并按起止时间排序，显示时间、类型、标题 / 状态和时长；窄屏大字允许行增长和滚动。Gap走现行初始化补记，事实进详情；面板不直接塞入编辑 / 删除。关闭后焦点回原段；原段已消失时回日轴的合法焦点，不能跳到失效对象。Web宽屏限制面板宽度或采用对话框，不变更候选集合与选择行为。

`h < 12dp`时省略块内文字，保留虚实线、空心 / 实心节点和状态色；Unknown还保留问号形状或可区分的节点样式，不能仅靠灰色。12dp在基础比例下对应10分钟；恰好12dp不强制省略，但仍按实测容纳选择内容。无论是否画文字，读屏和键盘均逐段可达。320dp大字场景优先减少图标 / 次要描述，完整信息仍由面板 / 详情和语义提供；仅在§4.1规定的实测条件下提高全轴比例，不按文字倍率逐级放大，也不限制系统文字缩放。第一版不做Pinch缩放。

**条件替代，尚未启用：** 若平台验收要求取消小目标例外，或32dp版本实测误触明显，切换严格版需记录验收依据：直接访问阈值提高到48dp（基础比例约40分钟），以下全部进选择面板，孤立段也不直达。严格版会让30多分钟的记录多一步。当前采用32dp便捷版，不因实现方便自动切换；严格版也不能靠扩大重叠热区宣称数据矩形已满足48dp尺寸，完整访问仍走标准面板行 / 语义 / 键盘路径。

### 4.5 当前时间、无记录与默认定位

推荐“现在 HH:mm”线落在今天 `window.endedAt`，与顶部时长来自**同次读取**。按 Q-029 进入 / 返回 / 恢复前台刷新，不新增每分钟刷新任务；持续停留时不让线先于投影前进。若将来要求实时时钟线，需同时决定投影刷新政策。

没有事实且 W 非空时，整段 W 仍画成明确的比例 Gap，而非空页面。午夜或未来日 W 为空时，不绘制虚构 Gap，不称为“已经全部交代”；已交代 / 尚未记录均为0只是空窗口状态。有完整覆盖的非空窗口可安静显示“已全部交代”，不评分。

默认阅读位置（Q-040用户决定）：今天让当前时刻落在可见时间轴下部，同时尽量保留前面几小时；历史日靠近第一条正式事实，Unknown 与 Sleep 同样属于正式事实；无事实历史日从00:00开始。所有更早时间仍可向上阅读，不裁掉首部 Gap。未来日保留空窗口表现，不在本轮扩展未来事实查询 / 展示。

默认定位完成仍先展示展开头部。可见小时数取决于真实视口，不固定保证08:00开始。上述具体定位已由用户选择；首次进入与显式切日使用该策略，普通刷新及返回保存时刻锚点。

## 5. 账本状态与情境卡

状态条消费同一个 `DayLedgerView` 的 accounted / unresolved。占比图按实际毫秒计算 `accounted / W`，W为0时画中性空轨道；只画覆盖关系，不展示“完成百分比”。数字沿已有时长格式与近似传播，Unknown不作为第三个大指标，也不恢复此前已明确删除的顶部Unknown说明。

展开态：360宽推荐两列时长、进度条在下方；412及更宽且测量通过时可把条放在中间。收起态：已定案保留已交代 / 尚未记录及真实时长的极简行，比例条可省略；窄屏 / 大字可换行，不默认隐藏状态。两态状态区域继续进入当前日摘要，不恢复Unknown第三指标。

情境卡建议保留 Q-028 / Q-029 的睡眠 > 记录 > 复盘、尾部Gap≥2小时、时间窗、设置开关、历史 / 未来问候和更新时机。本轮推荐只在展开态呈现，随收起消失；关闭提醒时不占空间。图片文案可以作为未来候选，不因此修改提醒触发或把提醒等同某个Gap。

底部两个按钮与其记录上下文不变；大字下允许按钮标签合理换行或操作栏增加高度，确保两入口和安全区都可访问。

### Engineering Recommendation：布局与状态协作

日轴把已排序 `segments + unresolvedSpans` 作为只读输入，计算日内位置并同时供刻度、轨道、块和命中使用，避免左右两套累计高度。绘制层不写事实，点击仍把原 segment / Gap 传给现有入口。

页头状态放在 presentation 中，由当前有效时间轴上报用户滚动；数据focusDate继续由已定位、当前有效的阅读窗口更新。对同一帧的页头尺寸、提示卡可见性、视口边界与锚点补偿统一处理，忽略恢复期间的滚动回调；退出动画层不可上报。页头与底部卡不能各自改变高度再相互追逐校正。

横向切日继续保留边缘32dp、水平最小64dp、真实水平位移大于垂直1.6倍的现有判定；收起只接受有效纵向阅读，不让点击短段、横滑、程序定位或多指手势误触状态转换。

阅读锚点推荐升级为“自然日 + 日内instant + 视口位置”，而非只保存事实行顶部：巨大Gap中的中间位置、填Gap拆段或删除事实后仍可恢复同一时刻。实现时同时保留源引用供详情返回和合法回退；头部补偿后只提交一次稳定焦点。

日期窗口加载继续复用现有controller；按日尺寸已知的比例轴可先用现有窗口和单一滚动容器，但实施时须测多日密集数据的构建 / 绘制成本。必要时仅把日块改成懒构建sliver，不能顺带重写repository或分页业务政策。

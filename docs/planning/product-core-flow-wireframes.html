窄屏、大字与Web规则

  • 布局宽320/360/412；文字1/1.5/2倍。图稿允许内容变高并滚动，不要求所有字段首屏可见；固定区域只保留标题与根导航，编辑页保存动作随正文可达。
  • 操作目标至少48逻辑像素。长标题和目标换行，说明不以悬浮提示作为唯一入口；读屏名称须说明时段、约号及动作。详情长文滚动，不截断首步全文。
  • 输入页键盘占位可预览，但不模拟Android实际inset；真实实现须测IME、输入焦点、滚动到错误与保存按钮。不能把浏览器文字倍率当Flutter文字缩放验收。
  • Web Tab按视觉顺序，Enter/Space激活；交互层需焦点圈定、关闭后归还触发器。此HTML用整屏切换展示面板内容，不证明模态焦点圈定已实现。浏览器后退与应用返回分别核对，不添加产品快捷键。
  • 今天、历史、未来、空数据的页面路径见H、HT、HF、H0；只改变读取窗口与文案，不重新决定允许未来事实的领域规则。

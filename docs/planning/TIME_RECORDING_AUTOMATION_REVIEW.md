# 时间自动化：直接预填与个人睡眠学习

日期：2026-10-07。阶段：需求与算法设计，不修改代码。本稿替换先前“必须采用候选才填值”的方案。

**已确认的产品要求：** 进入新建 / 补记直接得到完整日期和起止时间；以约80%的常见记录无需额外时间选择 / 修改为目标；其余情况也必须提供可修改初值。必须覆盖连续多日未记录、漏记睡眠。根据用户过往睡眠学习可能的睡眠时间，无历史时采用常规作息区间。进入时重新计算，不恢复旧缓存端点；同次编辑稳定，手动日期 / 时分按Q-038独立选择，保留现行整笔提交，不增加区间采用或实际结束确认步骤。追溯见[Q-036](../domain/OPEN_QUESTIONS.md#q-036)。

**已确认的活动分支：** 当前普通新建遇尾部连续Gap≥5小时，直接预填打开时刻前60分钟至打开时刻，优先于其他活动预测评分，较早空白保留。

**仍是候选：** 除已确认5小时 / 60分钟分支外，下文的具体默认时刻、样本窗口、学习权重、评分、冲突策略及验收容差。80%是目标，不是已测准确率；算法参数见[Q-037](../domain/OPEN_QUESTIONS.md#q-037)。

## 简洁设计稿

推荐采用“睡眠习惯预测 → 结合真实记录定位 → 自动选出一组起止 → 直接写入本次编辑缓存”。多个假设仅在算法内部比较，不向用户提出候选选择题，不因低把握就留空。

1. 主睡眠冷启动候选为本地23:00–次日07:00；有历史后改用个人常见睡眠模式，支持昼间睡眠和多种作息。小睡单独学习；没有小睡历史时先给最近30分钟，以上数值均为候选。
2. 根据个人模式生成各日期的可能睡眠窗口。实际已记录睡眠优先；未记录窗口仅用于计算初值，不自动写成睡眠、不填Unknown、不改变Gap / 统计。
3. 当前普通活动新建先判断真实尾部连续Gap：达到5小时（含边界）直接取最近60分钟。未触发此分支时，才比较接续与近期一笔；近期时长可来自相似历史，缺资料的30分钟仍候选。预测不覆盖已确认分支，不从几天前一路接到现在。
4. 睡眠初始化按入口日期 / Gap、个人模式和真实占用自动定位一次睡眠；取最适合本次入口的一段，不取第一个Gap，也不把整个空白都当作睡眠。
5. 常见情况直接使用初值；特殊情况用户在已有两端上改时间 / 日期 / 时长。完整事实更正使用自身输入，不重猜。

例如：尾部连续五小时或三天未记录，今天15:20新建活动，初值均为14:20–15:20；较早空白继续Gap，不要求没有活动历史。漏记主睡眠时，常规作息候选仍是前一日23:00–当日07:00；个人历史常见10:00–18:00则优先该白天区间。预测不保证还原正确，产品提供最佳可改估计。

## 1. 两层模型与输出合同

第一层学习时间习惯，第二层根据本次入口和账本约束选择具体日期及区间。三种几何上下文1/2/3作为输入保留，不再直接决定是否有端点。

输出始终包括完整的startedAt、endedAt和两端日期、默认approximate；另在应用编辑状态保留模型版本、依据及内部评分，帮助后续诊断 / 学习，不变成额外用户选择或新的睡眠生命周期。评分没有校准前不显示“概率90%”。

已给完整两端或一端加时长的用户输入优先；其余仍由模型给完整估计。正式记录更正、提交后收尾恢复沿既有合同。新建 / 补记每次重算；打开时刻t₀固定，本次编辑不随时钟、历史模型更新或标题变化漂移，不覆盖用户改过的端点。

## 2. 睡眠学习：联合学习区间，保留多种模式

### 数据与时间坐标

学习已发生的完整SleepSession，主睡眠 / 小睡分别建模，不以未记录日作“没睡”的负样本。依据实际发生日期排序，不以createdAt把近期补录的旧睡眠当新作息；未来结束记录暂不作为已发生训练样本，记录的正式合法性不受影响。

一条样本至少保留入睡本地时刻b、完整实际时长d、由此得到的醒来时刻和跨日关系；联合使用这些信息，避免分别平均入睡 / 醒来后拼出历史中并不存在的区间。事实时刻仍用UTC毫秒，实例化某天时通过设备日期 / 时区适配计算完整日期。

时刻按24小时圆处理，距离为`δ(b₁,b₂)=min(|b₁−b₂|, 24小时−|b₁−b₂|)`。23:50与00:10应属于午夜附近，而不会平均成中午。圆统计的这一依据见[SciPy官方circmean定义与例子](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.circmean.html)。

### 推荐首版：带权的联合模板 / 核密度

用历史真实区间作为联合模板，估计入睡相位与时长的多峰分布：

`p(b,d | 类型, 日期上下文) = 默认作息分量 + Σ(历史权重 × 圆时刻核 × 时长核)`

时长核使用正时长的对数距离，时刻核使用圆距离；每个分量保留一条样本的入睡与时长配对。默认分量是候选23:00–07:00，权重随有效个人信息增多下降，不把夜睡与昼睡平均成凌晨四点这种虚构折中。内部寻找不同峰，再按近期模式、日期上下文和本次可用范围选一峰；多峰圆分布有原始研究依据，但本文的睡眠应用和参数是产品算法建议，见[多峰圆分布研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC9042027/)。

预测代表取峰附近的联合模板 / 稳健代表区间，起止一并计算。学习的不只是平均时长，还包括区间位置、离散程度和不同模式的支持度。初版可在本机用小量样本完成，不要求引入深度学习库或远程服务。

近期记录权重更高；同时保留旧模式。单次熬夜先贡献一个次峰，多次近期一致的新时段提升该模式优先级。同星期等日历条件有足够独立样本时使用对应分布，否则回退总体个人分布，最终才回退常规作息。不把周一至周五自动认定为该用户的工作日，用户无需选择“现在是哪种作息”。

**长期未记录不是恢复常规作息的证据。** 学习窗口与衰减以最新可用睡眠的实际日期为基准，不能因为用户三天 / 一个月没记就把原来白天睡觉的模式清掉。较久没有观测可降低内部把握，但仍给完整个人估计；没有可用个人信息才使用默认。

主睡眠中的多段分别保留，不合成从最早入睡到最晚醒来的包络；相同醒来日可以有多次主睡眠。小睡历史不拉低主睡眠时长；没有小睡历史不推断每天存在午睡。

### 学习反馈不增加确认环节

用户正常提交即可，不要求“确认用于学习”。但训练权重要区分时间被手动调整、沿用预填和来源未知：

- 手动调整后的端点提供较强新信息；只改一端不把另一端也称为独立回忆。
- 原样使用模型初值可以作为弱反馈，不作为又一个等权独立样本。对这类反馈设置总权重上限，防止模型把自己重复预测的结果当作越来越强的证据。
- 旧记录没有来源字段，作为有限权重历史信息使用；不假定全部手工回忆。用户更正 / 删除后重算相关模型，不累计旧版本。

这是本产品的反馈控制建议。原始研究说明把自身生成标签再次用于学习应处理其不确定性，不能据此声称本产品已验证某种权重，见[PMLR自学习研究](https://proceedings.mlr.press/v204/rodriguez23a.html)。正常提交的睡眠仍是正式账本事实；训练权重不改变其统计时长。

## 3. 日期定位与未记录睡眠的内部预测

每次进入读取相关完整事实、左右真实邻居、个人睡眠分布和入口信息。算法区分浏览日可见Gap切片、跨日完整空白、用户此次补记焦点。午夜 / 查询边界仅是导航，完整区间可以跨多日。

| 入口 | 自动定位焦点（候选） |
| --- | --- |
| 今日普通活动新建 | t₀附近的近期事件；同时保留真实尾部接续假设 |
| Gap活动补记 | 所点片段作为日期焦点，结合完整空白；优先该焦点附近的未记活动段 |
| 今日普通睡眠 | 最近相关、尚未记录的预计睡眠；已结束窗口通常优先，当前预计睡眠 / 刚醒假设也参与比较 |
| 历史睡眠摘要补记 | 浏览日作为默认醒来日，开始可在之前日期；可手动改所有日期 |
| 跨多日Gap睡眠补记 | 生成该范围内每个醒来日的可能睡眠，优先靠近所点日期焦点的未记录一段；同分取靠右 / 较近一段，不选最早Gap |
| 未来日新建 | 仍给该日期上的估计端点；它是可修改初值，不把未来区域显示成待补Gap |

真实SleepSession覆盖相应窗口时，不再拿同一预计窗口作为漏记睡眠。真实活动 / Unknown在预计睡眠内占用时，须约束 / 调整预测区间，不能移动已有记录或忽略占用。

若前夜活动持续到03:00，个人睡眠常见23:00–07:00，可以比较03:00–11:00（时长保持）与03:00–07:00（时长缩短）的整体合理性，再给一组初值；不是一律把睡眠裁成剩余四小时。候选选择由联合分布、当前时刻、后续记录及入口日期决定，不要求用户先选择这两个答案。

普通入口在当前时刻附近还比较“刚醒”的完整区间：结束取t₀，开始结合个人时长。只在它符合个人时段、日期焦点和占用时提高排序；下午补昨晚睡眠不能一律醒于下午。未来正区间合法，但首选的回顾估计通常更靠近已结束的睡眠；没有合适已结束窗口时仍可给可修改的未来结束估计，不新增实际结束确认。

## 4. 活动初值：比较接续与近期一笔

### 已确认的优先分支：尾部连续Gap≥5小时

当前普通活动新建时，以打开时刻t₀截止的真实尾部连续Gap达到5小时，直接写入`开始=t₀−60分钟`、`结束=t₀`。此处使用完整跨日连续范围，不使用首页被午夜裁剪后的本日尾部长度；真实活动、Unknown和睡眠都中断空白，预测睡眠不改Gap。无前序事实时仅用现有已知对账窗口，不凭空假造更早历史。

该条件先于候选评分、活动时长学习及可能睡眠分段；即使有活动历史，也固定给本分支60分钟初值。按毫秒比较5小时边界，不以显示舍入后的小时数触发；同次编辑固定t₀，用户之后手动改动不被重算覆盖。原Gap比初值至少长四小时，未补部分继续Gap。此规则不是活动最长时长、不是自动提交 / 截断正式事实，也不改变其他开区间的30分钟建议。

本次决定针对当前普通新建；历史Gap补记、未来日和睡眠入口不擅自套用本条。它们仍获得完整估计，其他算法部分保留候选状态。

### 未触发优先分支时的候选模型

其他活动上下文生成完整候选，再内部选一组：

- 闭区间接续：完整[L,U)。保留原1的低成本优势，但它不总是获胜。
- 开区间接续：开始取真实前笔结束L，结束仍按既有`max(t₀,L+30分钟)`生成；若跨已知事实则不可作为可提交候选。
- 睡后 / 当前可用段接续：以已记录睡眠结束或本次预测睡眠结束为候选开始；预测依据只改变初值，不改变正式Gap。
- 近期单笔：结束接近t₀或所点Gap的相关边界，开始反推预测活动时长；缺少历史时候选30分钟。若可用段更短，比较该段与其他合理位置，不用30分钟当硬最短时长。

上述非优先分支的活动时长可用已知活动稳健分布：已有相同标题 / 上下文时优先相似样本，资料不足回退总体分布，再回退候选30分钟；不覆盖已确认长尾Gap的60分钟。Unknown和睡眠不作为普通活动时长样本；Goal / RhythmAnnotation只提供本次已有上下文，不由预测生成目标或节奏。此活动学习是候选增强，不增加分类 / 输入步骤，本次编辑不因后续改标题反复重算。

选取指标同时考虑：时长是否符合该活动模式、离日期焦点多远、与真实边界的关系、跨过多少可能睡眠、是否覆盖多个睡眠周期。相邻边界提供接续奖励；大量可能睡眠或很不符合历史的跨度降低接续评分。

这与“超过几小时截断”不同：经常持续四小时的活动可以优先接续四小时；同样四小时空白若跨本人睡眠窗口，或该活动通常十分钟，近期单笔更合适。真实长活动 / 长睡眠仍可输入任意正时长，模型不裁切 / 拒绝已明确输入。

多日尾部未记直接命中已确认5小时规则，不需要等整体接续的预测评分输给近期一笔。其他上下文仍比较可能睡眠与时长，过去未交代时间继续Gap；不自动生成几天睡眠、活动或Unknown。

## 5. 区间评分与冲突处理

已确认5小时 / 60分钟分支优先执行；未触发它的候选选择可表为：

`I* = argmin_I [习惯偏离 + 日期焦点偏离 + 接续代价 + 活动跨可能睡眠代价]`

其中：习惯偏离由联合睡眠分布或活动时长分布计算；日期焦点来自入口；接续代价体现真实边界的关联；活动跨可能睡眠代价按预测睡眠的支持度与相交时长累计。权重需通过样例 / 用户数据标定，不能把未校准评分称为概率。

真实占用是可提交区间的硬约束。算法可在写入任何正式事实之前移动 / 调整新估计，使其落在合适可用范围；这是初值求解，不是自动裁切已有事实。未知睡眠是软预测，不能当作已经占用的正式事实阻止用户输入夜间活动。

若唯一可用碎片只有几分钟，而模型拟补一段主睡眠，不能为了过校验就把八小时睡眠压成几分钟。比较调整后区间的习惯偏离，变形明显不合理时仍展示最合理的完整估计并指出现有冲突，用户在提供的端点上修正或更正原记录。具体变形容差属于候选参数；它控制初值策略，不限制用户合法时长。

即使低把握、多峰、历史不足或存在冲突，也不退回“先选范围 / 先选候选 / 两端留空”。输入错误 / 读取失败需告知，不能冒充成功读取了空账本；能生成的估计端点仍保留，提交用真实原子校验。

## 6. 具体场景检验

下表5小时 / 60分钟为已确认初值分支；23:00–07:00主睡眠及其他30分钟示例仍候选，可受个人模型影响。场景是推演，不是实现测试或80%达标证据。

| 场景 | 进入后的直接初值 / 结果 |
| --- | --- |
| 三天未记，今日15:20只想继续记录 | 固定14:20–15:20；不要求缺少活动历史，较早Gap保留 |
| 尾部Gap恰好5小时，今日15:20新建 | 固定14:20–15:20，边界触发 |
| 尾部Gap为4小时59分59.999秒 | 不触发5小时分支，走其他完整初值策略 |
| 前日18:00末笔结束，今日00:20新建 | 跨日Gap为6小时20分钟，初值前日23:20–今日00:20；不按本日20分钟误判 |
| 三天前有旧记录，但今日14:00已有实际睡眠结束，15:20新建 | 尾部Gap只有1小时20分钟，不因更早空白触发长尾分支 |
| 三天未记，补今天主睡眠 | 前一日23:00–今日07:00；不把三天合成一觉，也不自动记录另两夜 |
| 漏睡眠，前夜22:30结束、今晨09:00开始活动 | 睡眠初值前夜23:00–今日07:00；两侧空白保留，不把22:30–09:00整段归睡眠 |
| 两笔08:00–18:00，中间多件事 | 普通活动可给17:30–18:00；若已有相似活动习惯，可选另一更合理完整位置；不要求先选范围 |
| 个人常见10:00–18:00睡，凌晨活动 | 睡眠预填10:00–18:00；这段可能睡眠也影响活动接续估计，不按常规夜睡重置 |
| 08:00–18:00只补11:00–12:00 | 用户在初值上改到11:00–12:00；剩余两侧派生Gap，直接离开即可 |
| 实际一笔连续很长活动 / 睡眠 | 个人历史可增加此模式优先级；即使初值不合，用户改完整端点正常提交，不设长度上限 |
| 最近睡眠23:50与00:10开始 | 学到午夜附近的模式，不得到中午初值 |
| 夜睡23:00–07:00与昼睡10:00–18:00交替 | 保留两峰，近期模式 / 日期上下文 / 真实占用自动选一峰；不要求用户选作息 |
| 半年没记，先前多条昼间睡眠 | 保留个人白天睡觉的历史模式；缺观测不把它自动换回夜睡 |
| 临时晚睡一夜03:00–11:00 | 样本进入学习但不立即抹掉稳定原模式；近期多次一致后提升新模式 |
| 同日两次主睡眠，或多次小睡 | 单次区间逐笔预测 / 输入；已记录一段不代表全部，摘要合计各段实际时长，不吞清醒 |

## 8. 全应用合同与数据缺口

- 首页继续记录近期一笔，不要求先处理旧账；过去Gap仍可按日浏览 / 逐笔补。提醒现有时点与阈值只管提示，不能作为入睡 / 醒来端点。
- 预测睡眠仅是初值运算背景；正式保存前不进入时间线事实、睡眠摘要、日统计、目标投入或复盘，不自动抑制“尚未记录”提示。
- 活动 / 睡眠完整跨日保存；日贡献按窗口切片，睡眠整次按醒来日摘要，多次主睡眠与小睡分别汇总。不能因预测分段就持久化拆日事实。
- 部分补记后两侧剩余Gap自然派生；继续补记可选，Unknown必须明确记录，既有元数据合同保留。
- 未来正区间合法，但未来区域不产生Gap；无最短 / 最长时长，用户明确长区间优先。原子不重叠校验保留；后补事实只刷新派生背景，不改写复盘文字。

现有[SleepSession](../../lib/features/ledger/domain/sleep_session.dart)有完整端点、类型、createdAt / updatedAt，[持久化表](../../lib/features/ledger/data/sleep_sessions_table.dart)没有来源、用户改过哪一端或记录时区。不能用updatedAt代替时间修改来源。建议后续增加按睡眠身份关联的学习元数据 / 可重建派生模型，记录模型初值、实际提交值、端点修改和使用的时区；存放位置及迁移属Q-037候选，不能自动改变主事实字段合同。

[readWindow](../../lib/features/ledger/data/drift_ledger_repository.dart)能跨多日读取完整睡眠；[sleep_ledger_loader](../../lib/features/ledger/application/sleep_ledger_loader.dart)当前只读单日，实施需独立历史读取，不能用今天摘要作为个人历史。旧记录无原始时区，只能按当前设备时区投影并承认迁移不确定性；新学习元数据可帮助区分时区变化与作息变化，跨时区后仍提供完整初值，不自动改写旧事实。
